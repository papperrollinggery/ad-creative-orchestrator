# Roadmap

## Goal

Make Ad Creative Orchestrator a usable, credible, open-source project for Codex-first advertising creative operations, with the quality bar expected of a project that can earn 2k+ GitHub stars.

## Now

- Public `v0.3.3` release with packaged-document and source/package parity gates
- P0-P8 control plane from intake/current truth through feedback and next version
- Human Workspace v2 current-first indexes and schema-v2 lifecycle migration
- Fail-closed FinalDelivery inventory, rename, and supersession reconciliation
- Immutable PPT/client-package binding and separate independent review/send authorization
- Neutral specialist exchange with exact artifact/path/hash adoption boundaries
- Immutable Thread dispatch proof, bounded convergence, host reconciliation, and cleanup evidence
- Installable `adco` CLI, non-developer dashboard, JSON diagnostics, support bundle, and release checks
- GitHub Actions running `make release-check` on Python 3.10 and 3.12

## Next

1. Run external-user trials from `adco demo` to real project intake.
2. Turn external trial issues into focused CLI/dashboard/docs improvements.
3. Tighten first-five-minute onboarding from real user friction.
