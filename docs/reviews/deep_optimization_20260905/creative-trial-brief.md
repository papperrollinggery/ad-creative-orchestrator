# 轻合桌灯：内部广告草案（合成项目）
本文件是这个虚构品牌的完整事实来源，不需要外部品牌研究。

用户希望得到：两条机制不同的创意方向，推荐其中一条，并把推荐方向写成完整的20秒竖屏广告脚本；同时给出小红书三屏图文与电商详情页首屏的具体适配。
品牌：轻合。产品是一盏可以折平放进帆布袋、展开后放在桌面使用的便携桌灯。已确认的产品能力只有折平、展开和提供暖色照明。没有亮度、续航、重量、护眼认证或竞品比较数据。
目标：让经常在家临时腾桌工作的人想起“展开灯，开始眼前这一小段事”，建立折平/展开动作的品牌记忆。
受众状态：同一张桌子白天可能吃饭，晚上想写字，却总被桌面的杂物和没开始的犹豫拖延。这里是创作假设，不是调研结论。
制作范围：最长20秒，只有一位成年演员，只能在客厅的一张桌子拍摄。允许灯、一本本子、一支笔、帆布袋和少量餐具；不进入厨房、卧室或户外。实体产品必须可见，不能只靠灯光效果替代。
语气：安静、具体、有一点生活的幽默。不要教学腔；不能声称护眼、改善健康、提升效率，也不要虚构用户数据、奖项、时间日期或产品参数。
本轮是内部创意讨论。售价和最终包装图未提供，它们可以后续补充，当前脚本不涉及售价或包装细节。
