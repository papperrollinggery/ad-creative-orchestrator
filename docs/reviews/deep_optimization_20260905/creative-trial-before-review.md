## 内部广告成果｜轻合便携桌灯

目标是让经常临时腾桌工作的人记住一个动作：**展开灯，开始眼前这一小段事。**

受众的阻力不在于没有一个“理想书桌”，而是同一张桌子还停留在吃饭后的状态，令人迟迟无法开始。已确认的产品作用是：可折平、可放进帆布袋、可展开置于桌面并提供暖色照明。

### 方向一｜《借一下桌子》

**机制**：桌子不需要彻底收干净。人把餐具让出一小块位置，拿出折平的轻合并展开；灯一亮，桌子完成从“吃饭”到“做眼前这件事”的临时交接。

- **开场**：晚餐后，一张桌上留着少量餐具、帆布袋、本子和笔。人坐下，看着桌面，犹豫。
- **转折**：她不进行大扫除，只把餐具推到一侧，从帆布袋拿出折平的灯并展开。
- **收束**：暖色光落在本子上。餐桌仍是餐桌，但已经借出一小块地方给她写字。
- **品牌角色**：轻合不是背景灯光，而是完成“桌面交接”的实际动作。换成一盏不能折平、不能从帆布袋取出的普通灯，这条叙事就失去关键因果。
- **生产负担**：一位演员、一张客厅桌子、规定道具即可完成；重点是桌面前后状态与展开动作的清晰可见。

### 方向二｜《折平的借口》

**机制**：把“没准备好”的拖延，缩小成一个比写字更容易的动作：先从帆布袋拿出灯，再展开。开始不被表现成效率提升，而是一个可见、很小的决定。

- **开场**：人翻开又合上本子，笔在桌上转了一圈，迟迟没有落笔。
- **转折**：她看见帆布袋，拿出折平的轻合。展开灯的动作成为当晚第一个明确动作。
- **收束**：她终于在本子上写下第一行。桌面上的餐具还在，房间也没有变，只是眼前多了一段被照亮的事。
- **品牌角色**：折平放进帆布袋、取出展开，是“先做一个小动作”的叙事发动机；普通固定桌灯无法承担这个从袋中取出、展开后开始的动作链。
- **生产负担**：同样符合单人、单桌限制，但需要更细的表演和剪辑节奏，才能让“犹豫”不显得拖沓。

### 推荐｜《借一下桌子》

推荐方向一。它更直接地把产品动作和受众处境连起来：不是抽象地说“开始”，而是看见一张餐桌怎样被借出一小块位置。折平、取出、展开、暖色照明四项已知能力都进入了画面，且全程不需要产品参数或效果承诺。它也更适合建立“展开灯，开始眼前这一小段事”的长期动作记忆。

## 20 秒竖屏广告脚本｜《借一下桌子》

**画幅**：9:16  
**地点**：客厅同一张桌子  
**演员**：一位成年演员  
**道具**：轻合桌灯、帆布袋、一本本子、一支笔、少量餐具

| 时间 | 画面与动作 | 声音 / 文案 |
|---|---|---|
| 0–2 秒 | 俯拍桌面：一只碗、一只盘子、一双筷子靠在一侧；本子和笔被挤在桌边。帆布袋在椅背上。演员坐下，看了桌面一眼。 | 环境底声。演员轻声：**“又得借一下桌子。”** |
| 2–5 秒 | 中近景。她不收走餐具，只把碗、盘和筷子往桌子远侧轻轻挪开，留出本子宽的一小块位置。 | 餐具轻碰桌面的声音。 |
| 5–8 秒 | 特写。她从帆布袋取出一盏折平的轻合，放到本子旁。产品完整可见。 | 布料摩擦声。 |
| 8–11 秒 | 手部特写。她把灯展开并放稳在桌面，暖色光落到本子和笔上。 | 安静的音乐进入。 |
| 11–15 秒 | 侧面中景。餐具仍在画面一侧，演员坐进那一小块空位，翻开本子，拿起笔。 | 笔尖落纸声。 |
| 15–18 秒 | 俯拍。桌面分成两个自然区域：一侧是吃完饭的餐具，另一侧是打开的灯和正在书写的本子。 | 旁白：**“吃饭的桌子，先借我一小会儿。”** |
| 18–20 秒 | 干净的产品收束：展开的轻合在桌面上，暖色光照着本子；演员的手仍在画面内书写。 | 画面文案：**轻合**  \|  **展开灯，开始眼前这一小段事。** |

口播共两句，置于开场与后段自然停顿中，适合 20 秒内安静的表演节奏。成片不出现售价、包装、参数、认证、效率或健康承诺。

## 小红书三屏图文适配

三张均采用同一位演员、同一张桌子、同一晚间暖色基调；重点不是从广告截三帧，而是让用户每划一屏完成一次叙事推进。

**第一屏｜“桌子还是餐桌”**

- 画面：3:4 竖图，俯拍或微斜俯拍。餐具占据桌面中心，本子和笔停在边缘，演员刚坐下，帆布袋挂在椅背。
- 主文案：**今晚想写点东西。**
- 副文案：**但桌子还没下班。**
- 作用：把“临时腾桌”的具体困境摆在第一屏，不预先承诺产品效果。

**第二屏｜“借出一小块”**

- 画面：连续动作感构图。演员把餐具推向一侧，另一只手从帆布袋取出折平的轻合；在画面下方或右侧保留一张小的展开后状态局部，确保产品折平与展开都可识别。
- 主文案：**不用把整张桌子清空。**
- 副文案：**先从帆布袋拿出轻合，展开。**
- 作用：把产品的可见动作作为解决方式，避免只用氛围图代替实体产品。

**第三屏｜“开始眼前这一小段事”**

- 画面：俯拍完成状态。左侧保留少量餐具，右侧是展开的轻合、本子与正在写字的手；暖色光集中在本子区域。
- 主文案：**餐桌，先借我一小会儿。**
- 落版：**轻合｜展开灯，开始眼前这一小段事。**
- 发布文案建议：**有些晚上不用等桌子变得完美。给眼前这件事留一小块地方，就可以开始。**
- 话题建议：`#轻合桌灯 #临时工作角 #客厅桌面`

## 电商详情页首屏适配

首屏应先把已确认的产品形态与使用动作讲清楚，再进入后续详情；不使用缺乏依据的性能卖点。

- **版式**：移动端竖向首屏。上半部分为同一张客厅桌子的双状态画面：左侧是折平的轻合靠在帆布袋旁，右侧是展开的轻合放在本子旁并提供暖色照明。两侧以手部动作形成自然衔接。
- **主标题**：**轻合便携桌灯**
- **主句**：**折平放进帆布袋，展开，留一小块桌面给眼前的事。**
- **事实信息条**：**可折平｜可展开桌面使用｜暖色照明**
- **辅助场景句**：**餐桌还在用，也能先开始写这一页。**
- **首屏视觉要求**：产品在折平态和展开态都要清晰、足够大；保留少量餐具和本子以说明使用语境；不出现包装盒、售价、虚构规格或认证标识。
- **首屏后的第一模块建议**：用三张连续近景展示“折平 → 放入帆布袋 → 展开放在桌面”，只陈述动作与已确认能力。

### 事实边界

- **已确认**：轻合可折平、可放入帆布袋、可展开置于桌面、提供暖色照明。
- **创作假设**：同一张桌子白天吃饭、晚上想写字；餐具与犹豫构成开始前的阻力。
- **当前未知且未使用**：亮度、续航、重量、护眼认证、售价、包装、竞品比较、用户数据与奖项。
