# 客户追问话术

## 建议询问

```text
我们先按品牌官方视觉资产和过往 campaign 做一轮 reference audit，再进入视觉方向设计。请确认：这次第一轮提案更希望看到 KV/mockup/BTS/产品细节方向，还是需要直接看到分镜故事线？
```

## 原因

```text
Moncler 类视觉提案如果没有官方参考和资产边界，容易生成“看起来高级但不可用”的图。
```

## 可复制话术

```text
我这边建议先锁两个点：
1. 第一轮提案的视觉产物形态：KV/mockup/BTS/产品细节，还是 storyboard？
2. 是否允许我们用 AI 生成图作为内部视觉参考，客户稿前再筛选和标注？
```
