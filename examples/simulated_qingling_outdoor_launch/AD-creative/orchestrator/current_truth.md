# Current Truth

## Project

青岭户外 2026 春夏新品「云壳防晒冲锋衣」上市传播。

目标产物：

```text
30 秒短片创意方向
第一轮客户可审方案结构
每方向 moodboard / 摄影参考 / 6 个关键画面
后续可转可编辑 PPT
```

## Confirmed

```text
需要 2 个方向。
OP1 情绪向：城市到自然的生活感。
OP2 功能向：天气变化也能轻松应对。
第一轮每个方向至少 6 个关键画面。
客户重视参考视频链接。
不要极限户外、硬核登山、滑雪、高山、攀岩。
不要假 logo、未经授权明星、夸张机能风。
模拟用户已批准国内平台和品牌/竞品视频参考搜索。
AI 图在当前模拟中保持 internal_only。
视觉资产必须先锁人物 / 产品 / 环境 / 风格，再生成关键帧。
缺官方产品图时，产品只能做 placeholder，不进入客户稿。
```

## Inferred

```text
第一轮更像 moodboard + key frames + reference video，不是完整 storyboard。
导演组建议可以作为执行解法，但不能覆盖客户需求。
视觉参考应优先国内平台和轻户外/城市生活方式案例。
```
