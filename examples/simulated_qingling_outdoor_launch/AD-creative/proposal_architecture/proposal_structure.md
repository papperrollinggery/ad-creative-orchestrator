## Client Review Goal

```text
第一轮让客户判断两条创意路线、视觉气质、参考方向和关键画面是否对。
不在第一轮锁最终 PPT 版式、不锁最终 slogan、不交付最终分镜。
```

## Direction Pages

### OP1 城市到自然

```text
页面重点：生活方式、自然过渡、轻户外情绪。
画面优先级：清晨窗边 > 树影通勤 > 绿道步行 > 周末轻露营。
产品露出：低压、生活化、面料轻动。
```

### OP2 天气变化也能轻松应对

```text
页面重点：多天气切换、状态稳定、产品细节可信。
画面优先级：强光 > 风 > 小雨 > 袖口/帽檐/拉链/收纳。
产品露出：功能证据优先，但不写未经确认参数。
```

## Reference Pages

```text
当前模拟 reference pack 只允许内部使用。
真实项目必须替换为真实链接、截图来源、平台、可引用说明。
客户稿里不能出现模拟引用或未经核验来源。
```

## Visual Asset Slots

```text
下一阶段拆为：
1. 人物设计：城市年轻白领 / 周末轻户外状态
2. 产品设计：云壳防晒冲锋衣外观、颜色、细节
3. 环境设计：城市通勤、办公室、绿道、轻露营
4. 画面设计：每方向 6 个 key frames
5. PPT 主视觉：和创意风格一致，但独立评估版式需求
```

## Open Questions

4. 参考视频是否需要真实链接和截图进入客户稿？
