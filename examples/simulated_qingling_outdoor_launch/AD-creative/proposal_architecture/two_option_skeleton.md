# Two-option Proposal Skeleton

artifact_id: ART-QLO-002
status: draft
visibility: internal_only

## OP1

```text
方向：城市到自然
角色：情绪向
核心感觉：一个普通工作日，也能往自然走近一点。
```

关键画面草案：

```text
1. 清晨衣料在窗边被风轻轻带起
2. 通勤路上树影落在外套表面
3. 地铁口微雨后反光路面
4. 办公室椅背上的外套
5. 下班后换到城市边缘的绿色步道
6. 周末轻露营，外套抵住风和日晒
```

## OP2

```text
方向：天气变化也能轻松应对
角色：功能向
核心感觉：城市天气不需要计划太多，一件外套让状态继续。
```

关键画面草案：

```text
1. 出门前看天气，手拿轻薄外套
2. 阳光强烈的通勤路
3. 云层变化，风吹起衣摆
4. 小雨落在袖口和肩线
5. 产品细节近景：帽檐、袖口、拉链、面料水珠
6. 傍晚户外活动，人物状态轻松
```

## Copy Rule

```text
可作为内部 mood 参考。
```
