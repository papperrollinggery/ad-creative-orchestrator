# PPT Visual System

artifact_id: ART-QLO-024
status: done
visibility: internal_only

## Deck Design Role

```text
PPT 是客户判断创意方向的阅读工具。
设计要清晰、克制、可编辑，避免像最终广告成片或重视觉海报。
```

## Film Visual Role

```text
片子视觉要服务 OP1/OP2 的画面感、摄影参考和 moodboard。
它可以和 PPT 气质一致，但不必完全等同于 PPT 版式。
```

## Shared Style

```text
浅自然光
城市中性灰
低饱和绿色
大留白
照片/视频参考优先
细窄线框和清晰编号
```

## Divergence Rules

| Situation | Decision |
|---|---|
| 客户只审结构 | 用文本和占位符，不做重视觉 |
| 客户重视美观第一印象 | 先生成 PPT 主视觉参考图，再做版式 |
| 片子方向未锁 | PPT 保持中性，不把某个方向包装成已定稿 |
| 产品资产缺失 | 产品图全部占位，不伪造品牌产品 |

## Placeholder Rules

```text
未过 Visual Review 的图只能做内部参考。
客户稿中占位符必须清楚标记用途，但不能写内部备注。
产品细节页必须等官方图或明确 placeholder approval。
```
