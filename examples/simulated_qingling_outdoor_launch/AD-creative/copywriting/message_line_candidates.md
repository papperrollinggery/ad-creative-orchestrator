# Message Line Candidates

artifact_id: ART-QLO-013
status: internal_review
visibility: internal_only

## Rules

```text
不使用已废弃主 slogan：把风景穿在身上。
不虚构防晒指数、防水等级、面料科技名。
每条文案必须绑定方向和画面作用。
客户审阅前需由客户确认产品卖点和禁用词。
```

## OP1 城市到自然

| Line | Role | Risk |
|---|---|---|
| 城市里的每一步，也可以靠近自然。 | 主张 | 安全 |
| 从通勤到周末，让轻风一直跟着你。 | 情绪补充 | “轻风”需画面支持 |
| 把日常穿得更轻一点。 | 产品态度 | 安全 |
| 去自然，不必等到远方。 | 结尾句 | 安全 |

## OP2 天气变化也能轻松应对

| Line | Role | Risk |
|---|---|---|
| 天气会变，状态不用变。 | 主张 | 安全 |
| 阳光、微风、小雨，都不打断今天。 | 场景说明 | 需避免暗示硬防水 |
| 一件轻外套，应对城市里的多种天气。 | 产品说明 | 需客户确认“多种天气”口径 |
| 轻一点出门，稳一点到达。 | 结尾句 | 安全 |

## Not For Client Yet

```text
防晒科技
全天候防护
专业防水
高性能户外
```

## Recommendation

```text
第一轮客户稿用 OP1/OP2 的方向标题和一句话，不急着锁最终 slogan。
等客户确认产品参数后，再升级功能向文案。
```
