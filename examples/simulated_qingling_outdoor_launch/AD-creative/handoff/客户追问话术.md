# 客户追问话术

## 建议询问

```text
我们已按 2 个方向整理：OP1 情绪向、OP2 功能向。为了保证第一轮视觉方向准确，需要补充几个执行资料：
1. 产品高清图 / 三个主推颜色图 / 面料细节图
2. logo 使用规范和品牌字体/色彩规范
3. 防晒、防小雨、轻量这些功能的官方可用表述
4. 是否有必须参考或必须避开的竞品案例
```

## 原因

```text
缺少这些资料时，AI 参考图和 PPT mockup 只能做内部探索，不能进入客户可见稿。
```

## 可复制话术

```text
我们这边先按“城市到自然”和“天气变化轻松应对”两个方向推进。想跟您确认几个素材点：
1. 能否提供产品高清图、面料细节图、三个主推色的官方图？
2. logo 使用规范和品牌视觉规范是否可以同步？
3. 防晒、防小雨、轻量这些功能有没有官方固定说法？
4. 第一轮提案是否可以用 AI 图作为内部视觉参考，客户稿前我们再筛选和标注？
```
