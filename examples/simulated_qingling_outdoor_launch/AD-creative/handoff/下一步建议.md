# 下一步建议

## 推荐动作

```text
把这套模板用于下一个真实项目的第一轮 intake。
```

## 执行方式

```text
1. 运行 `adco init <project_dir>` 初始化真实项目。
2. 把客户资料放入 `00_项目资料_ProjectMaterials/`。
3. 运行 `adco run <project_dir> --material <material_file_or_folder>` 登记资料并更新当前事实。
4. 运行 `adco next <project_dir>` 读取当前阻塞与下一步。
5. 每个关键阶段后运行 `adco validate <project_dir>`。
```
