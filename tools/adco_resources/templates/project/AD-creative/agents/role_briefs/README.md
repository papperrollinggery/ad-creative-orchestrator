# Role Briefs

Project-specific role briefs live here.

Use this folder to adapt optional Agent Agency staff files to the actual project. Configure the staff-library path locally when one is available; do not edit upstream staff files for project-specific needs.

Each role brief must name:

```text
source_staff_paths
agency_selection_id
project facts to honor
work_id objective
what to extract
what to ignore
critical rules
workflow to follow
deliverable template
output contract
forbidden actions
acceptance evidence
```

Role briefs are project-specific summaries, not copied staff prompts.

Rules:

```text
Use 2-4 selected source staff files per lane unless the selection record explains otherwise.
Extract only identity standards, critical rules, workflow, and deliverable templates.
Ignore upstream model/tool/frontmatter choices.
Keep AD-creative thread budget, version safety, write scope, and final export rules higher priority.
Do not put prompts, execution steps, thread plans, or staff descriptions into client-facing deck pages.
```
