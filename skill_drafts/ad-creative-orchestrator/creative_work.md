# Direct Creative Work

Read this file for an internal brief, concept, script, storyboard, treatment,
proposal content, or ordinary revision. Work directly from inspected material;
do not create a candidate contract, version, Gate, Specialist handoff, or PPT
merely because the task is creative.

## Build the idea

1. State the objective and the audience's behavior or resistance that matters.
2. Ground the product's role in supplied evidence. Where the evidence supports
   only category ownership, say so instead of inventing exclusivity.
3. Turn that causal role into a visible mechanism: what a person does, sees,
   hears, chooses, or changes because the product is present.
4. Adapt the execution to each requested channel; a crop, caption, or slogan
   swap alone is not an adaptation.

When offering directions, vary the causal mechanism, not just the tagline,
setting, or styling. Explain which route you recommend and why its evidence,
audience behavior, brand role, and production burden fit the objective. Run a
brand-replacement test against plausible substitutes: the named product must
cause the mechanism to work rather than decorate it.

Compare each route's setup, turning point and payoff with its title, captions
and tone removed. If these still match, revise the duplicate before presenting
it; a humorous telling of the same action chain is not a second mechanism.
The product's signature action may stay shared when the narrative logic differs.
For a multi-route recommendation, compare the nearest functional substitute,
not only a less capable product. Shared category utility is not brand exclusivity.
If distinct routes still collapse into the same mechanism after self-review,
use one read-only second judgment on the brief and actual drafts when available,
then replace the duplicate before delivery. Keep this review on the Content
Surface; it needs no Council, Gate, persistent receipt or nested reviewers.

Give the requested artifact in usable form. A script includes action, dialogue
or voice where relevant, and a closing beat. A treatment makes cause and effect
readable before a technical shot list. A client proposal completes the content
and its story logic before PPT work; do not cut the core idea merely to fit a
page count. For film, reject attractive frames that break causal continuity,
world rules, asset truth, or the latest user override.
Check the spoken copy against the time available in its actual beat. Read it
at the intended performance pace; shorten it or start it earlier if it cannot fit.
When a still contains two moments or product states, name the collage or split
layout explicitly so the production plan does not demand an impossible instant.

## Facts and constraints

Separate confirmed facts, supported inference, and unknowns. Do not present
invented product claims, effects, data, endorsements, client approval, or results
as facts. Fictional scenes and proposed actions are allowed when they do not
contradict supplied facts or a stated restriction. If the brief forbids invented
facts/data/numbers or confines locations, apply that rule literally, including
close euphemisms and physical sub-locations. Production timecodes, runtime, and
cast count describe the proposed artifact and remain allowed.

Before answering, silently map every explicit hard constraint to the draft and
repair violations. Do not call a route lowest, easiest, or safest without a
visible comparison of the relevant production burden.

## Revise and finish

On revision, retain the adopted direction, voice, register, and latest explicit
change. Change only the affected scope unless the new instruction invalidates a
dependency. Produce first, then run one focused review against the main creative
problem and repair what it finds. Continue only for a concrete remaining defect;
do not loop for a score or invent process records.

An internal second judgment stays on the Content Surface and is returned directly.
Use the durable contract only for cross-model/provider exchange, imported
candidates, or a versioned decision that must bind exact evidence.
